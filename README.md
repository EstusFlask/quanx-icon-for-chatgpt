# ChatGPT Icon for Quantumult X

A ChatGPT PNG icon asset for Quantumult X configurations.

用于 Quantumult X 配置的 ChatGPT PNG 图标素材。

## Asset / 素材

Use [`chatgpticon.png`](chatgpticon.png) from the `master` branch. The original repository notes specify the **108 px** PNG.

请使用 `master` 分支中的 [`chatgpticon.png`](chatgpticon.png)，即原说明标注的 **108 px** PNG。

When a configuration needs a remote image URL, open the image and copy its **Raw** URL. This repository contains the icon only, not routing rules, a ChatGPT client, or a Quantumult X application.

配置需要远程图片地址时，打开图片并复制 **Raw** 地址。本仓库仅提供图标，不包含分流规则或应用程序。
